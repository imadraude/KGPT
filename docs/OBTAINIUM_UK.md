# Автоматичні оновлення KGPT через Obtainium

Джерело застосунку: https://github.com/imadraude/KGPT

## Що налаштовано в репозиторії

- GitHub Actions `.github/workflows/obtainium-release.yml` збирає й підписує release-APK.
- Коміти до `feature/chatgpt-plan-oauth` створюють **попередні релізи** (теги `v4.2.0-rc.N`).
- Після схвалення та злиття змін у `main`, нові коміти до `main` створюватимуть звичайні релізи (`v4.2.N`).
- Версія APK та Android `versionCode` збільшуються автоматично. Встановлені версії оновлюватимуться без видалення **за умови того самого ключа підпису**.
- На кожному релізі перевіряються сертифікат підпису, ідентифікатор пакета `tn.eluea.kgpt` та обчислюється SHA-256.
- Реліз містить один APK і контрольну суму. Підпис зі сторонніх репозиторіїв НЕ використовується.

## Одноразова дія: додати секрети підпису

**Не надсилати секрети до Git, у коментарі PR, issue, обговорення або журнал GitHub Actions.**

1. Завантажте приватний резервний архів ключа та розпакуйте у надійному місці.
2. Зробіть резервну копію файлів `kgpt_release.jks` та `github_actions_secrets.txt` у приватному сховищі: при втраті ключа неможливо надалі оновлювати APK зі старим підписом.
3. Відкрийте: https://github.com/imadraude/KGPT/settings/secrets/actions
4. Створіть репозиторні секрети (Repository secrets):
   - `KGPT_KEYSTORE_B64`: суцільний довгий рядок із `github_actions_secrets.txt`.
   - `KGPT_STORE_PASSWORD`: пароль із того самого файлу.
5. Відкрийте останній невдалий запуск **KGPT Obtainium signed releases**, натисніть **Re-run jobs**. Невдалий запуск до додавання секретів — очікуваний захист від випуску випадково непідписаного APK.
6. Перевірте, що з'явився **Releases** із позначкою попередньої версії та файлом `KGPT-release-v*.apk`.

Після цього нові коміти у відповідній гілці публікуватимуть підписані релізи без ручного завантаження APK. **Секрети не доступні для неперевірених pull request**, бо workflow публікації запускається лише на довірених гілках.

## Додати до Obtainium

1. На телефоні відкрийте **Obtainium → Додати застосунок**.
2. Вставте: `https://github.com/imadraude/KGPT`.
3. Джерело має бути **GitHub**.
4. Увімкніть **«Включати попередні випуски» / Include prereleases**, доки користуєтеся тестовою гілкою.
5. Рекомендований фільтр APK за регулярним виразом: `^KGPT-release-v.*\.apk# Автоматичні оновлення KGPT через Obtainium

### Важливо щодо підпису

Раніше зібрані APK у **Actions → Artifacts** підписані тимчасовим debug-ключем. Вони можуть **не оновлюватися поверх** нового release-APK, навіть якщо назва й ідентифікатор пакета однакові. Якщо Android повідомить про конфлікт підпису — збережіть налаштування/дані, видаліть старий KGPT та встановіть перший стабільно підписаний APK із Releases. Не видаляйте SwiftKey: це окремий застосунок.

Згодом **не змінюйте** `KGPT_KEYSTORE_B64`, якщо хочете встановлювати нові версії поверх старих. Для релізів іншої гілки використовуйте **той самий ключ**.

## Статус

Автоматична публікація GitHub Release не почнеться до додавання двох секретів. Поки їх немає, Obtainium може додати джерело, але не матиме APK для встановлення.
